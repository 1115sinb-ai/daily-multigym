# DAILY MULTI GYM · PUNCH YOUR DAY

데일리 멀티짐(PUNCH DAILY)의 브랜드 및 가맹 안내용 반응형 웹사이트입니다.

## 웹사이트

[공개 사이트 바로가기](https://daily-multigym-2026.amplesong17.chatgpt.site)

## 구성

- `index.html` — 브랜드 소개, 트레이닝 프로그램, 매장 사례, 가맹 안내, 사회적 가치
- `styles.css` — 데스크톱·모바일 반응형 스타일
- `script.js` — 모바일 메뉴, 스크롤 효과, 12장 이미지 갤러리
- `assets/` — 제공된 브랜드·사업소개 이미지 12장

## 로컬에서 실행

별도 빌드나 의존성 설치 없이 정적 웹서버로 실행할 수 있습니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.
