# DAILY MULTI GYM — Brand & Franchise Landing Page

반응형 정적 브랜드 랜딩페이지입니다. 전달받은 브랜드 홍보·사업소개 이미지와 인계본점의 추가 운영 실적 자료를 사용해 제작했습니다.

## 실행

별도 빌드 과정이 없습니다. `dist/index.html`을 웹서버로 제공하면 됩니다.

```bash
cd dist
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 구성

- `dist/index.html`: 페이지 구조와 콘텐츠
- `dist/styles.css`: 반응형 스타일
- `dist/script.js`: 모바일 메뉴, 스크롤 전환, 이미지 갤러리
- `dist/assets/`: 브랜드 자료 이미지 11장과 인계본점 오픈 3개월 실적 화면 1장
- 브랜드 이미지 갤러리는 자료에 기재된 `01 BRAND IDENTITY`부터 `08 SOCIAL IMPACT`까지 번호 순서로 배치했습니다. 비번호 이미지와 추가 실적 화면은 그 뒤에 나옵니다.
- 예약관리 캡처에 포함된 고객 이름·개인 전화번호·예약번호는 공개하지 않고, `144건`이라는 예약 집계만 사이트 문구에 반영했습니다. 전화번호가 인쇄된 기존 협력 홍보 이미지도 공개 자산에서 제외했습니다.

## 게시 전 확인 사항

- 상담 연락처는 현재 사이트에 표시하지 않습니다. 공개 가능한 공식 문의 채널이 정해지면 추가하세요.
- 매출 사례, 투자금, 예상 순이익, 투자금 회수 목표치의 기준·기간 검증
- 인계본점 신규 3개월 자료와 기존 브랜드 홍보 자료의 매출 집계 기준·기간을 별도로 확인
- 실제 사업자명, 개인정보처리방침, 연락처 등 운영 정보 보완
- 제공 이미지와 브랜드 로고에 대한 사용 권한 확인

> 수익 및 투자 관련 내용은 제공 자료의 사례 또는 목표값으로 표시했으며, 결과를 보장하는 표현으로 사용하지 않았습니다.
